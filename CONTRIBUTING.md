# Contributing to Digital To-Do & Wellness Manager

Thank you for your interest in contributing to the **Digital To-Do & Wellness Manager**! We welcome contributions from developers worldwide.

## 🚀 How Can You Contribute?

1. **Reporting Bugs**: Open an issue using the Bug Report template detailing steps to reproduce.
2. **Suggesting Features**: Open an issue using the Feature Request template explaining the use case.
3. **Submitting Pull Requests**:
   - Fork the repository.
   - Create a feature branch: `git checkout -b feature/your-feature-name`.
   - Ensure all tests pass: `python manage.py test tests/`.
   - Follow PEP 8 style standards.
   - Submit a Pull Request targeting the `main` branch.

## 🧪 Testing Guidelines

Before opening a PR, always run:
```bash
python manage.py test tests/
```
Ensure test coverage is maintained for any newly added features or bug fixes.
